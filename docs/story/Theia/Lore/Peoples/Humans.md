# Humans

Alliance: [Covenant](../Institutions/Covenant.md).

Judge-created, principally Guardian-worshipping; unified monarchy based on ancestral great inland plains. Separate hereditary branch of royal dynasty supplies the **Covenant High Ruler**, whose alliance capital is a great mixed-race coastal metropolis.
