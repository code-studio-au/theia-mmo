# Using This Vault

Start at [[Welcome]]. Use the character, location and quest tables to browse; use [[Source Reading Maps]] for complete section coverage.

## What a note means
- Sources contains preserved reference copies. Source labels and later explicit creator decisions govern canon.
- Extracted character, location and quest pages are derived references, with source links and approval scope.
- Reading pages embed source sections; an embed may include related subjects.
- Related-note links identify text references, not proof of friendship, physical proximity or causal responsibility.
- Story truth, player revelation and gameplay implementation remain separate.

## Updating material
Record new explicit creator decisions with date, scope and evidence. Update affected derived notes and both source locations deliberately. No automatic synchronisation is configured. Preserve superseded choices as history.

## Maps and visuals
No source map images or authoritative coordinates have been supplied. Interactive geographic maps remain dependent on those inputs. Existing Atlas pages provide the supported travel topology.

## Review limits
This organisation does not approve proposals, complete the absent PDF audit or establish implemented gameplay. Bases and embeds need visual inspection in Obsidian; filesystem checks cannot verify their appearance.
