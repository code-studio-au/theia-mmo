# Documentation archive

Historical documents are kept here when they contain unique evidence, decisions,
source provenance or reproduction details for retained code. Their versions,
next steps and permissions apply only to the recorded checkpoint.
Use the [active documentation index](../README.md) for current entry points.

| Collection | Why it is retained |
| --- | --- |
| [Forest](forest/README.md) | Frozen environment imports, source fidelity and regression evidence |
| [Handoffs](handoffs/README.md) | Earlier release/editor/UI session checkpoints |
| [Validation](validation/README.md) | Dated asset and performance measurements |
| [Experiments](experiments/README.md) | Deferred work and comparative research |
| [Engineering](engineering/README.md) | Original architecture, audits and previous progress/queue snapshots |

Archiving a document does not remove its code, assets, fixtures or tests. Active
format contracts and preparation guides remain in their subject folders even
when their initial qualification is old. Licenses remain beside the vendored
code and assets. Exact duplicate prose can be removed when the retained source
is identified; unique evidence stays available here.
