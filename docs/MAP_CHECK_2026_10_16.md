## Offline terrain conversion

The converter uses [trimesh's standard OBJ exchange](https://trimesh.org/trimesh.exchange.obj.html)
and [glTF export](https://trimesh.org/trimesh.exchange.gltf.html), pinned separately
from the Rust runtime. No custom runtime OBJ loader or game asset format was added.

```sh
python3 -m venv build/asset-tools
build/asset-tools/bin/python -m pip install -r tools/requirements-assets.txt
mkdir -p build/map-preview
build/asset-tools/bin/python tools/convert_terrain.py /home/steven/wow.export/maps/2999/adt_31_27.obj build/map-preview/terrain.glb > build/map-preview/conversion.json
cargo run --locked -p theia-client -- --inspect-asset build/map-preview/terrain.glb
```

The output must be a new file. All terrain material textures must exist; missing
files cause failure instead of untextured fallback. The converter checks material
grouping/triangle conservation and input hashes before/after conversion. It retains
authored UVs/normals and creates opaque, rough, nonmetallic PBR materials with a
neutral base colour unless MTL authors a diffuse tint. This is a texture-based
preview, not a recreation of the original game's terrain shaders.

The checked GLB is 588,585,816 bytes, with 256 mesh instances and 65,504 triangles.
Two source PNGs (`tex_31_27_62.png` and `tex_31_27_127.png`) are identical, so the
export shares them: 255 images/materials cover all 256 patches. Decoded RGBA pixels
for every patch were compared to its source PNG and match exactly. Embedded PNG
encoding may differ, while pixel data is preserved.

SHA-256: `c010f9bf0bab6dec369426d6718fc4023509b949fe3792b54a082772dd988160`.
Khronos Validator `2.0.0-dev.3.10`, without an issue cap, reports zero errors,
warnings or informational messages. It emits 516 `BUFFER_VIEW_TARGET_MISSING`
hints about optional buffer targets; the report is not truncated.

The existing inspector now expands the camera depth range and scales wheel zoom
for large assets. It keeps a bounded 60-second load and 90-second capture timeout;
the previous 30-second loading limit left little margin for this large texture set.
Add `--capture <directory>` for an actual PNG and `asset.json`, or use orbit/zoom
interactively. The 1.8-unit capsule becomes tiny at full-tile viewing distance.
