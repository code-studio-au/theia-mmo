# Original development cues

`cast.wav` and `impact.wav` are original deterministic synthesized tones, generated
by `python3 tools/generate_development_audio.py` using only Python's standard
library. They contain no recordings, imported samples or third-party music.
16 kHz mono signed 16-bit PCM; 0.12 / 0.18 seconds. The amplitude envelope is
intentionally quiet. These are prototype feedback assets, not final sound design.
